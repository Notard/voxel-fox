여우가 타일 위를 걷고 점프하며, 구멍에 들어가면 아래로 떨어진다.

4애니메이션 연결

Idle⇄ Speed > 0.1Walk · Any → Jump (trigger) → Idle (IsGrounded)

걷는 속도와 Walk 재생 속도를 맞춰서 발이 미끄러져 보이지 않게 합니다.

멈춤 → Idle, 이동 → Walk, 점프 → Jump가 자연스럽게 전환된다.

5아이템

  • 복셀 코인 4개를 레이아웃의 아이템 위치에 배치
  • 제자리에서 회전하며 위아래로 둥실둥실 움직임
  • Trigger Collider에 닿으면 획득 → 사라지면서 간단한 파티클
  • 좌상단 UI: 아이템 0 / 4
아이템을 먹으면 카운트가 오르고 아이템이 사라진다.

6게임 종료 / 성공

Playing → Y < −5 →GAME OVER / 아이템 4/4 →CLEAR!

두 경우 모두 결과 패널이 뜨고 조작이 멈춥니다. 성공 화면에는 걸린 시간을 보여줄 수도 있습니다(선택).

두 조건 모두에서 해당 패널이 뜨고 더 이상 조작되지 않는다.

7재시작

  • 결과 패널의 [다시 하기] 버튼, 또는 언제든 R 키
  • SceneManager.LoadScene으로 현재 씬을 다시 불러와 전체 초기화
재시작하면 여우 위치, 아이템, UI가 모두 처음 상태로 돌아온다.
